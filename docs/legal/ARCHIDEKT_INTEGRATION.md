# Archidekt integration

Laatst beoordeeld: 13 augustus 2026.

De Archidekt-integratie valt onder de algemene publieke providergrens in
[`PROVIDER_INTEGRATIONS.md`](PROVIDER_INTEGRATIONS.md).

Voor MTG Battle Arena is projectspecifieke schriftelijke bevestiging ontvangen
voor de beschreven user-triggered import-use-case, met als hoofdgrenzen dat het
project niet crawlt en de grenzen van de dienst respecteert. De originele
correspondentie wordt privé bewaard en wordt niet in deze publieke repository
gepubliceerd.

Officiële publieke voorwaarden: https://archidekt.com/terms
